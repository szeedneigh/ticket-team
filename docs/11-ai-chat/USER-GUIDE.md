1. **Via Chat Page**: Navigate to `/chat`
2. **Via Chat Widget**: Click the chat icon in the bottom-right corner

### Your First Conversation

Timi greets you with suggested questions and common topics.

## How to Use Timi

### Asking Questions

**Good Questions:**
- ✅ "How do I reset my student portal password?"
- ✅ "What are the library hours on weekends?"
- ✅ "I can't access my email, what should I do?"

**Tips:**
1. Be specific with details
2. Ask one question at a time
3. Provide context (error messages, what you tried)
4. Use natural language

### Features

- **Message History**: Auto-saved conversations
- **Context Awareness**: Remembers conversation flow
- **Source Citations**: KB articles with relevance scores
- **Streaming**: Real-time responses (2-5 seconds)

## Understanding Responses

### Confidence Levels

| Level | Meaning | Action |
|-------|---------|--------|
| High (>80%) | Strong match | Follow guidance |
| Medium (50-80%) | Partial info | Review carefully |
| Low (<50%) | Limited info | Create ticket |

## Best Practices

### ✅ Do's

1. Ask clear, specific questions
2. Provide error details
3. Follow steps in order
4. Search history first

### ❌ Don'ts

1. Share passwords/sensitive data
2. Ask multiple unrelated questions
3. Expect hardware repairs
4. Spam (10 msg/min limit)

## When to Escalate

Create ticket when:
- Timi suggests escalation
- Need IT staff intervention
- Solutions don't work
- Urgent assistance needed

## Common Questions

**Q: Can Timi access my account?**
A: No. Only reads public KB articles.

**Q: Is chat private?**
A: Yes. Only you and IT admins see it.

**Q: Rate limiting?**
A: 10 messages/minute prevents abuse.

**Q: What can Timi help with?**
A: Passwords, portals, library, IT policies, tech FAQs.

**Q: What can't Timi do?**
A: Password resets, account creation, software installs, billing.

## Troubleshooting

### Rate Limit Error
Wait 60 seconds.

### Service Unavailable
Wait 2-3 minutes, retry.

### Incorrect Response
1. Click "Not Helpful"
2. Rephrase question
3. Create ticket

### Widget Missing
1. Refresh (F5)
2. Clear cache
3. Try different browser

# ADR 0003: Choose Gemini API for AI

## Status
Accepted

## Context
We need a capable LLM with strong reasoning and safety tooling, accessible via API.

## Decision
Adopt Google's Gemini API for AI interactions.

## Consequences
- Pros: High capability models; safety controls; broad ecosystem.
- Cons: Ongoing API costs; vendor dependency.

## Alternatives Considered
- OpenAI: comparable capability; cost/terms vary.
- Local models: infra overhead; quality variance; maintenance burden.
